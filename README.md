# ⚡ Turbo Toads: Neon Run

An original browser platformer made with **HTML, CSS, and JavaScript**.

## 🎮 Controls

- **A / D** or **Left / Right arrows** — move
- **W / Up arrow / Space** — jump
- **Restart** — restart the level

## 🎯 Goal

Collect coins, avoid or stomp enemies, and reach the glowing portal at the end of the level.

## 🚀 Run locally

Open `index.html` in a browser.

For GitHub Pages, upload the project and enable Pages for the repository.
